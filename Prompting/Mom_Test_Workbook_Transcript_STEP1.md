# Part D — STEP 1 워크북 작성

**입력 (Mom Test 결과):**

- **페르소나:** 길이 단위 변환 스크립트를 반복 수동 조작하다 에러·시간 낭비를 겪는 작업자
- **진짜 문제:** 입력 오타 → 에러 없이 중단 → 30분+ 수동 추적·재작업 → 메모장 검사·복붙 우회
- **증거 3줄:** (1) 에러 없이 뻗음 (2) 30분+ 터미널·소스·엑셀 (3) 메모장 선작성·복붙

**요청:** STEP 1 워크북 — 주제, R-G-I-O, 성공 기준 3, 표면 문제, 8계층(Rule/Command/Skill/Test Loop)

---

## D-1. 주제 한 문장 (초안)

`단위:값` 형식을 반복 입력하는 작업자가 오타(콜론 누락, 공백, 잘못된 단위) 때문에 원인을 못 찾고 30분 넘게 수동 추적·재작업하는 일을 없애기 위해, 잘못된 입력마다 즉시 무엇이 틀렸는지 알려주는 검증과 변환 로직을 만든다.

---

## D-2. R-G-I-O

| 항목 | 내용 |
|------|------|
| Role | Python으로 길이 단위 변환 스크립트를 리팩토링·검증하는 개발자 |
| Goal | `meter:2.5` 정확 변환 + 오타·음수 등 즉시 이해 가능한 메시지 |
| Input | 터미널 한 줄. 오타: `meter 9.1`, `meter:`, `:2.5`, `feet:abc`, `meter:-1` |
| Output | 정상 변환 / 오류 시 원인 드러나는 메시지 (묵살 종료 금지) |

---

## D-3. 성공 기준 3개

- **SC-1:** 콜론 누락·공백 시 조용히 뻗지 않고 명확한 오류 메시지 (→ 증거 1)
- **SC-2:** 소스·엑셀 대조 없이 메시지만으로 몇 초 안에 원인 특정 (→ 증거 2)
- **SC-3:** 정상·오류 TC 자동 검증 — 메모장 수동 검사 대체 (→ 증거 3)

---

## D-4. 표면 문제 (제외)

화려한 GUI, 외부 JSON 설정, 대규모 아키텍처, 배치 입력 등.

---

## D-5. 8계층 핵심

- **Rule:** OCP/SRP, 묵살 종료 금지
- **Command:** 구조 분석 → 검증 분리 → 리팩토링 → TC → Review
- **Skill:** 파싱·pytest·Mom Test 추적
- **Test Loop:** SC-1~3 기반 정상·오류 TC + Mom Test 체크
